title: Your first card
description: From a model of your home to a card in a dashboard.

  order: 2
---

1. **Model your home**, for example with [Sweet Home 3D](http://www.sweethome3d.com/), and export it as OBJ (*3D view › Export to OBJ format*), or convert it to GLB: see [Modelling your home](/floor3d-card/model/sweet-home-3d/).
2. **Copy the files of the model** into a folder of `/config/www`, for example `/config/www/floor3d/`. For the card that folder is `/local/floor3d/`.
3. **Add the card**: in a dashboard, add **floor3d-card mod** from the card picker. The editor opens on the *3D model* section: set the folder and the file of the model.
4. **Add the entities**: for each one choose its type and pick its object with a tap on the model in the preview: see [The card editor](/floor3d-card/editor/overview/).

The video tutorials of the original card still show how a model is made and bound to the entities:
